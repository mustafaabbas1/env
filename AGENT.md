# Overview
This project defines scripts that helps a user set up their computer with the requisite tools to get developing quickly.

# Structure
./setup.sh -> the top level script that the user runs to install the tools needed
./tools/<tool>/setup.sh -> each individual tool file that the top level file will run
./changelog/ -> folder that contains changelogs that you should read to build up a reference of past changes made with AI, to implement future changes.
